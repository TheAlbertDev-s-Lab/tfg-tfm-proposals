# TFG/TFM Proposals

This repository is used as an **issue tracker** to manage proposals for Bachelor's Theses (TFG) and Master's Theses (TFM).

## Purpose

Each GitHub issue in this repository represents a proposal for a TFG/TFM project. This allows proposals to be organized, discussed, and tracked in a transparent and structured way, using labels, comments, and status updates as they evolve.

## Interested in proposing your own topic?

If you have an idea for a TFG/TFM project and would like to discuss it, please get in touch with me. You should be able to find my contact details through the university.
